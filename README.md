# our-wedding-rsvp-site

A simple static wedding invitation and RSVP site.

## Local preview

Because the app is fully static, you can preview it with any file server. For example:

```bash
cd /home/runner/work/our-wedding-rsvp-site/our-wedding-rsvp-site
python3 -m http.server 4173
```

Then open `http://localhost:4173/`.
